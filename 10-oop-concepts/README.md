# OOP As It Should Be - Concepts (C++)

Welcome to the **OOP As It Should Be** repository! This project contains a comprehensive, step-by-step collection of lessons, exercises, and projects covering Object-Oriented Programming (OOP) concepts using C++.

## 🎯 Overview

This course is designed to take you from the absolute basics of classes and objects to advanced OOP architecture, including polymorphism, abstract classes, and memory management. Each folder represents a specific lesson containing its source code (`.cpp`) and Visual Studio project files.

## 📚 Course Structure

The repository is logically divided into several key areas of Object-Oriented Programming:

### 1. The Basics of OOP
- **Lesson 02:** Classes and Objects
- **Lesson 03:** Class Members
- **Lesson 04:** Object in Memory
- **Lesson 05:** Access Specifiers & Modifiers
- **Lessons 06 - 08:** Properties (Getters & Setters, Read-Only Properties, Overloading `=`)

### 2. The Core Principles of OOP
- **Lesson 09:** First Principle - Encapsulation
- **Lesson 10:** Second Principle - Abstraction
- **Lesson 20:** Third Principle - Inheritance
- **Lesson 28:** Virtual Functions (Introduction to Polymorphism)

### 3. Lifecycle of an Object
- **Lesson 13:** Constructors
- **Lesson 14:** Copy Constructors
- **Lesson 15:** Destructors
- **Lesson 21:** Parameterized Constructor of the Base Class

### 4. Advanced Inheritance & Polymorphism
- **Lesson 22:** Function Overriding
- **Lesson 23:** Multi-Level Inheritance
- **Lessons 24 - 26:** Inheritance Access Specifiers, Visibility Modes, and Inheritance Types
- **Lesson 27:** Up-Casting vs Down-Casting
- **Lesson 29:** Static (Early) Binding vs Dynamic (Late) Binding
- **Lesson 31:** Interfaces, Pure Virtual Functions, and Abstract Classes

### 5. Advanced Class Features
- **Lessons 16 & 17:** Static Members (Variables & Methods)
- **Lesson 32:** Friend Classes
- **Lesson 33:** Friend Functions
- **Lesson 34:** Structure Inside a Class
- **Lesson 35:** Nested Classes

### 6. Projects & Applied Exercises
- **Lesson 12:** Project 1 - Calculator
- **Lesson 19:** Person Exercise

## 🚀 Getting Started

### Prerequisites
- Basic knowledge of C++ fundamentals (Variables, Control Flow, Functions, Arrays, and Pointers).
- An IDE installed on your machine (Preferably **Visual Studio** since the project files are included, but CLion or VS Code will also work).

## 🚀 Quick Start (CLI)

```bash
# Clone the repository and navigate to a lesson
git clone [https://github.com/Valkenan/10-OOP-as-it-Should-Be-Concepts.git](https://github.com/Valkenan/10-OOP-as-it-Should-Be-Concepts.git)
cd 10-OOP-as-it-Should-Be-Concepts/LESSON_2_CLASSES_AND_OBJECTS

# Compile and run
g++ LESSON_2_CLASSES_AND_OBJECTS.cpp -o main
./main
